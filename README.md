# Web Build PC v2.0.1

Khu vực Admin được tích hợp trực tiếp thành một trang trong website, không còn mở bằng hộp nổi.

## Tab chính khi đăng nhập Admin
`Admin → Build PC → Hướng dẫn`

## Tab con trong Admin
- Sản phẩm
- Tài khoản
- Báo giá
- Yêu cầu đặt hàng
- Cấu hình mẫu
- Mẫu báo giá
- Admin

Không cần chạy SQL mới cho phiên bản này.
